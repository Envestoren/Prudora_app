# Design System Document

This document outlines the core aesthetic and functional principles of our design system.

## Theme Overview

Our design language emphasizes a modern and sophisticated aesthetic, balancing functionality with an engaging user experience. The current theme is set to `light` mode.

## Colors

The brand's primary color is `#4F6F52`, a rich and earthy tone, providing a strong foundation for interactive elements. A complementary secondary color, `#86A789`, offers a harmonious balance, suitable for supporting UI components. The neutral base color, `#F8FAF8`, ensures a clean and accessible backdrop for content.

## Typography

Our typography system uses `Manrope` across all text elements—headlines, body text, and labels—to maintain a consistent, modern, and highly legible visual rhythm.

## Shape and Form

**Roundedness:** We adopt a maximum roundedness (pill-shaped) for UI elements, ensuring a soft, friendly, and contemporary feel.

## Spacing

**Density:** A normal level of spacing is applied throughout the UI, striking a balance between information density and visual comfort.
